# 数据库设计

当前项目没有独立服务端数据库。所谓“数据库设计”实际指本地 Hive 与 `flutter_secure_storage` 的数据结构设计，以及两者之间的一致性约束。

---

## 1. 存储分层

| 存储层 | 工具 | 内容 | 是否敏感 |
|--------|------|------|----------|
| 结构化持久化 | Hive | 服务器配置、设置、AI 对话、端口转发、快捷命令等 | 否 |
| 敏感凭证 | `flutter_secure_storage` | SSH 密码、私钥、AI 远端服务密码 | 是 |

说明:

- 当前设置也存放在 Hive 中，不再使用 `SharedPreferences`。
- 云端同步、账号体系、订阅没有进入当前存储模型。

---

## 2. Hive Box 一览

| Box 名称 | 模型 / 结构 | 用途 |
|----------|-------------|------|
| `servers` | `ServerConfig` | 服务器基础配置，不含敏感凭证 |
| `ssh_key_profiles` | `SshKeyProfile` | 密钥中心元数据，不含私钥明文 |
| `host_groups` | `HostGroup` | 服务器分组 |
| `port_forward_profiles` | `PortForwardProfile` | 本地 / 远程端口转发配置 |
| `quick_commands` | `QuickCommand` | 快捷命令 |
| `known_hosts` | `KnownHost` | 已信任主机指纹记录 |
| `settings` | `AppSettings` | 应用设置，固定 key 为 `app_settings` |
| `ai_tool_configs` | `AIToolConfig` | AI 工具配置 |
| `ai_conversations` | `AIConversation` | AI 对话头信息 |
| `ai_chat_messages` | `AIChatMessage` | AI 消息明细 |
| `ai_tool_detection_cache` | `Map<String, dynamic>` | AI 工具检测结果与最近成功路径缓存 |

## 3. 核心模型

### 3.1 `ServerConfig`

保存非敏感连接配置。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `String` | 服务器 ID |
| `name` | `String` | 显示名称 |
| `host` / `port` | `String` / `int` | SSH 地址 |
| `username` | `String` | 登录用户名 |
| `authType` | `AuthType` | `password` / `privateKey` |
| `createdAt` / `lastConnected` | `DateTime` | 创建时间 / 最后连接时间 |
| `connectTimeout` | `int` | 连接超时秒数 |
| `colorHint` | `bool` | 终端彩色输出偏好 |
| `sshKeyId` | `String?` | 关联密钥中心 key ID |
| `jumpServerIds` | `List<String>` | 跳板机链 |
| `groupId` | `String?` | 分组 ID |
| `isFavorite` | `bool` | 收藏状态 |
| `transport` | `ConnectionTransport` | 当前仅 `ssh` 有运行时实现，`mosh` 为预留值 |

### 3.2 `SshKeyProfile`

保存密钥中心元数据，不保存私钥明文。

| 字段 | 说明 |
|------|------|
| `id` | key ID |
| `name` | 密钥名称 |
| `algorithm` | 算法，如 RSA / Ed25519 |
| `fingerprint` | 指纹 |
| `publicKey` | 公钥内容 |
| `comment` | 备注 |
| `createdAt` / `updatedAt` | 时间戳 |
| `hasPassphrase` | 是否存在口令 |

### 3.3 `KnownHost`

| 字段 | 说明 |
|------|------|
| `host` / `port` | 主机地址 |
| `fingerprint` | 指纹 |
| `algorithm` | 指纹算法 |
| `firstSeen` / `lastSeen` | 首次 / 最近接受时间 |

### 3.4 `PortForwardProfile`

| 字段 | 说明 |
|------|------|
| `serverId` | 所属服务器 |
| `label` | 配置名称 |
| `direction` | `local` / `remote` |
| `bindHost` / `bindPort` | 本地或远端监听地址 |
| `targetHost` / `targetPort` | 被转发目标地址 |
| `autoStart` | 连接成功后是否自动启动 |

### 3.5 `QuickCommand`

| 字段 | 说明 |
|------|------|
| `name` / `command` | 名称与命令内容 |
| `description` | 说明 |
| `order` | 排序 |
| `scopeType` | `global` / `server` |
| `serverId` | 服务级作用域时对应服务器 |
| `sendMode` | `exec` / `typeOnly` |

### 3.6 `AppSettings`

| 字段 | 说明 |
|------|------|
| `themeMode` | `dark` / `light` / `system` |
| `terminalTheme` | 终端配色标识 |
| `fontSize` | 字体大小 |
| `locale` | 语言 |
| `autoReconnect` | 自动重连 |
| `heartbeatInterval` | 心跳间隔 |
| `enableTabSwipe` | 标签页滑动切换 |
| `enablePinchZoom` | 双指缩放 |

### 3.7 `AIToolConfig`

| 字段 | 说明 |
|------|------|
| `serverId` | 所属服务器 |
| `adapterId` | `opencode` / `openclaw` / 其他适配器 |
| `displayName` | 展示名 |
| `command` | 启动命令模板 |
| `mode` | `http` / `execute` / `pty` |
| `httpPort` | HTTP 端口，可选 |
| `envVars` | 环境变量，可选 |
| `autoDetect` | 是否自动检测 |

### 3.8 `AIConversation`

| 字段 | 说明 |
|------|------|
| `serverId` | 所属服务器 |
| `toolConfigId` | 所属工具配置 |
| `title` | 标题，通常来自首条消息摘要 |
| `createdAt` / `updatedAt` | 时间戳 |
| `sessionContext` | 远端会话上下文，例如 OpenClaw session key |

### 3.9 `AIChatMessage`

| 字段 | 说明 |
|------|------|
| `conversationId` | 所属对话 |
| `role` | `user` / `assistant` / `system` / `error` |
| `content` | Markdown 文本 |
| `timestamp` | 时间戳 |
| `isComplete` | 是否为完整消息 |

### 3.10 `ai_tool_detection_cache`

未使用强类型 Hive 模型，按 `serverId -> Map` 保存：

- `detectionResults`
- `lastSuccessful`
- `updatedAt`

这是运行时缓存，不是强一致业务数据。

## 4. Secure Storage Key 设计

### 4.1 服务器级凭证

| Key 模板 | 用途 |
|----------|------|
| `ssh_password_{serverId}` | 服务器密码 |
| `ssh_key_{serverId}` | legacy 私钥明文 |
| `ssh_passphrase_{serverId}` | legacy 私钥口令 |

### 4.2 密钥中心

| Key 模板 | 用途 |
|----------|------|
| `ssh_key_profile_private_{keyId}` | 私钥中心中的私钥明文 |
| `ssh_key_profile_passphrase_{keyId}` | 私钥中心中的口令 |

### 4.3 AI 远端服务密码

| Key 模板 | 用途 |
|----------|------|
| `opencode_server_password_{serverId}` | OpenCode serve 密码 |
| `openclaw_gateway_password_{serverId}` | OpenClaw gateway 密码 |

## 5. 一致性与迁移策略

### 5.1 写入一致性

- `ServerRepository` 写配置时先读取旧凭证快照。
- 若 Hive 或安全存储任意一步失败，则回滚配置和凭证。
- 删除服务器时同时清理:
  - 密码
  - OpenCode / OpenClaw 服务密码
  - legacy 私钥与口令

### 5.2 Android 安全存储迁移

- 当前启用 `migrateOnAlgorithmChange: true`。
- 使用 v9 兼容的 cipher 组合，减少升级到 `flutter_secure_storage 10` 后的读取失败。
- 仓库层对常见迁移错误提供可读错误消息。

### 5.3 兼容旧数据

- 旧版“按服务器保存私钥”的模型仍可读取。
- 新版鼓励使用 `ssh_key_profiles` + `sshKeyId`。
- `QuickCommand` 对旧字段布局也保留了解析兼容。

## 6. 当前不包含的数据

- 云端同步配置
- 账号 / 订阅记录
- 远端 Shell 会话跨进程快照
- 任何服务端 PostgreSQL / Redis 结构
