本清单只覆盖当前仓库已经存在的后端与运行链路，不包含前端交互、视觉验收和历史规划中的云服务功能。

## 2. 发布前必须完成的后端验证

### 2.1 基础工程链路

- [ ] `dart run tool/verify.dart analyze`
- [ ] `dart run tool/verify.dart test`
- [ ] `dart run tool/verify.dart build-apk`
- [ ] GitHub Actions `analyze` / `test` / `build` 三条流水线均为绿色
- [ ] `*.g.dart` 生成文件已提交，没有生成物漂移

### 2.2 SSH 真机联调

- [ ] 密码认证可成功连接
- [ ] 私钥认证可成功连接
- [ ] 首次连接会弹出指纹确认，接受后可落盘
- [ ] 指纹变化时会拒绝连接
- [ ] 跳板机链路可成功打通
- [ ] 同一服务器可打开多个 Session
- [ ] 断网 / 恢复网络后能自动重连
- [ ] 重连后可恢复需要重建的 Shell

### 2.3 端口转发联调

- [ ] 本地转发可用
- [ ] 远程转发可用
- [ ] `autoStart` 配置在重连后仍可恢复
- [ ] 连接关闭时隧道会正确清理

### 2.4 AI 运行链路联调

- [ ] 服务器安装 OpenCode 时能被检测到
- [ ] `opencode serve` 未运行时可由应用自动启动
- [ ] OpenCode HTTP 模式能创建会话、发送消息、中断
- [ ] OpenCode HTTP 不可用时可降级到 PTY
- [ ] 服务器安装 OpenClaw 时能被检测到
- [ ] `openclaw gateway` 未运行时可由应用自动启动
- [ ] OpenClaw `/v1/chat/completions` 可返回 SSE
- [ ] OpenClaw HTTP 不可用时可降级到 execute / PTY
- [ ] AI 会话标题、消息、sessionContext 可正确持久化
- [ ] AI 中断后会保存不完整消息而不是丢失输出

### 2.5 存储与安全验证

- [ ] 删除服务器时会清理服务器密码和 legacy 私钥
- [ ] 删除密钥中心条目时会清理对应私钥与口令
- [ ] 旧版 `flutter_secure_storage` 数据在升级后仍可读取
- [ ] OpenCode / OpenClaw 远端服务密码只进 Secure Storage，不进入 Hive
- [ ] 日志中不输出密码、私钥明文、Bearer token
