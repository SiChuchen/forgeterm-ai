## 3. 2026-04-06 前后的新增收口

### 3.1 当前模型来源与已配置模型列表收口

已通过真实服务器和 OpenCode 源码核对，确认：

- 当前服务器默认模型应以 `/config.model` 为准
- `/config/providers` 只是“已配置 provider 及其候选默认模型”
- `/provider` 是总表，不能直接当聊天页当前模型来源

已完成的修复：

- 聊天页顶部与高级设置优先显示真实当前模型
- 不再把 provider 默认项误显示成当前生效模型
- 模型列表只展示已配置项，不再混入总 provider 列表
- OpenCode 配置入口已收回到高级设置，不再放在加号面板里伪装成“添加模型”

### 3.2 空回复、错误状态与 transcript 覆盖收口

已完成的修复：

- `session.status` 中服务端返回的结构化错误会直接展示，不再表现成“没回复”
- 远端 transcript 覆盖本地消息的条件已收紧，不再只靠条数和最后一条角色判断
- slash command 的原始用户输入已改为优先保留，避免被后续远端历史再抹掉

### 3.3 slash command 接入完成

当前代码已经完成：

- 输入框 slash popup
- 真实 `/command` 列表复用
- inline slash command 一次性执行
- 命令请求固定走 OpenCode HTTP，不再错误回退到 PTY
- `/session/:id/command` 超时后继续轮询历史与状态，避免“第一次没任何输出”
- 命令执行后保留本地原始 `/<command> ...` 用户消息

已确认：

- `flutter analyze` 通过
- `flutter build apk --debug --target-platform android-arm64` 通过
- debug APK 已成功安装到真机
- 真机普通 OpenCode 提问链路可用

- provider 登录/登出、fork / children / todo / diff 等剩余 OpenCode 能力仍未图形化
