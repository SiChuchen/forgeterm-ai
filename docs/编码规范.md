## 1. Dart/Flutter 编码规范

### 1.1 命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| 类名 | UpperCamelCase | `ServerConfig`, `SSHService` |
| 文件名 | snake_case | `server_config.dart`, `ssh_service.dart` |
| 变量名 | lowerCamelCase | `serverList`, `isConnected` |
| 常量 | lowerCamelCase | `maxRetryCount`, `defaultTimeout` |
| 枚举值 | lowerCamelCase | `AuthType.password` |
| 私有变量 | `_lowerCamelCase` | `_connection` |

### 1.2 类结构

```dart
// 1. imports
import 'package:flutter/material.dart';
import '../models/server_config.dart';

// 2. class declaration
class ServerConfig {
  // 3. constants / static fields
  static const int defaultPort = 22;
  static const int maxTimeout = 30;

  // 4. instance fields
  final String id;
  final String name;
  
  // 5. constructor
  ServerConfig({
    required this.id,
    required this.name,
  });

  // 6. named constructors
  ServerConfig.empty() : this(id: '', name: '');
  
  // 7. factory constructors
  factory ServerConfig.fromJson(Map<String, dynamic> json) {
    return ServerConfig(
      id: json['id'] as String,
      name: json['name'] as String,
    );
  }

  // 8. methods
  Map<String, dynamic> toJson() => {
    'id': id,
    'name': name,
  };

  // 9. getters
  bool get isValid => id.isNotEmpty && name.isNotEmpty;

  // 10. @override
  @override
  String toString() => 'ServerConfig(id: $id, name: $name)';
}
```

### 1.3 Widget 规范

```dart
class ServerCard extends StatelessWidget {
  // 1. Props - 使用 final 字段
  final ServerConfig server;
  final VoidCallback? onTap;
  final VoidCallback? onEdit;
  final VoidCallback? onDelete;

  // 2. Constructor - 使用 const
  const ServerCard({
    super.key,
    required this.server,
    this.onTap,
    this.onEdit,
    this.onDelete,
  });

  // 3. Build - 保持简短
  @override
  Widget build(BuildContext context) {
    return Card(
      child: InkWell(
        onTap: onTap,
        child: Padding(
          padding: const EdgeInsets.all(16.0),
          child: Row(
            children: [
              _buildIcon(),
              const SizedBox(width: 16),
              _buildContent(),
              _buildActions(),
            ],
          ),
        ),
      ),
    );
  }

  // 4. 私有方法 - 拆分复杂 UI
  Widget _buildIcon() => Icon(Icons.server);
  
  Widget _buildContent() => Expanded(
    child: Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [
        Text(server.name),
        Text(server.host),
      ],
    ),
  );
  
  Widget _buildActions() => Row(
    mainAxisSize: MainAxisSize.min,
    children: [
      IconButton(icon: const Icon(Icons.edit), onPressed: onEdit),
      IconButton(icon: const Icon(Icons.delete), onPressed: onDelete),
    ],
  );
}
```

```dart
class ServerListNotifier extends StateNotifier<List<ServerConfig>> {

    state = [...state, server];

    state = state.map((s) => s.id == server.id ? server : s).toList();
```

## 3. 异步编程规范

### 3.1 async/await

```dart
// Good
Future<ServerConfig?> connect(String serverId) async {
  try {
    final config = await repository.getById(serverId);
    if (config == null) return null;
    
    final client = await sshService.connect(config);
    return config;
  } on SocketException {
    rethrow; // 保持原始异常
  } catch (e, st) {
    // 记录并转换
    Logger.e('Connection failed', e, st);
    throw ConnectionException(e.toString());
  }
}
```

### 3.2 Stream

```dart
// 流式输出处理
Stream<String> executeCommand(String command) async* {

    yield utf8.decode(data);
  }
}
```

## 4. 错误处理规范

### 4.1 自定义异常

```dart
class SSHException implements Exception {
  final String message;
  final String? code;
  
  SSHException(this.message, [this.code]);
  
  @override
  String toString() => 'SSHException: $message (code: $code)';
}

class ConnectionException extends SSHException {
  ConnectionException(super.message);
}

class AuthenticationException extends SSHException {
  AuthenticationException(super.message);
}
```

### 4.2 Result 类型

```dart
// 使用 sealed class 替代 try-catch
sealed class Result<T> {
  const Result();
}

final class Success<T> extends Result<T> {
  final T data;
  const Success(this.data);
}

final class Failure<T> extends Result<T> {
  final String message;
  final Object? error;
  const Failure(this.message, [this.error]);
}

// 使用
Result<ServerConfig> connect(String id) async {
  try {
    final config = await repository.getById(id);
    return Success(config);
  } catch (e) {
    return Failure('连接失败', e);
  }
}
```

## 7. Git 提交规范

### 7.1 Commit Message 格式

```
<type>(<scope>): <subject>

<body>

<footer>
```

### 7.2 Type

| type | 说明 |
|------|------|
| feat | 新功能 |
| fix | Bug 修复 |
| docs | 文档更新 |
| style | 代码格式 |
| refactor | 重构 |
| test | 测试 |
| chore | 构建/工具 |

