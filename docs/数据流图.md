# 数据流图

本文档只保留当前代码真实存在的后端数据流与运行链路，移除尚未接入的账号体系 / 云同步等规划流。

---

## 1. 应用启动与存储初始化

```text
main()
  │
  ▼
HiveInitService.init()
  │
  ├─ 注册 Hive 适配器
  ├─ 打开 servers / settings / known_hosts / ai_conversations ...
  └─ 打开 ai_tool_detection_cache
  ▼
ProviderScope 启动
```

说明:

- 所有后端持久化依赖都在应用启动时初始化。
- 当前没有远端数据库初始化步骤。

---

## 2. SSH 建连数据流

```text
ServerRepository
  ├─ Hive: ServerConfig
  └─ SecureStorage: password / privateKey / passphrase
        │
        ▼
ConnectionRegistry.ensureConnected(serverId)
        │
        ▼
ServerConnectionController.connect()
        │
        ├─ 解析 jumpServerIds
        ├─ 读取凭证
        └─ 调用 SSHService.connect / connectViaJumpHosts
                │
                ├─ 查询 KnownHostRepository
                │    ├─ 命中 -> 校验 algorithm + fingerprint
                │    └─ 未命中 -> 走 TOFU 回调并落盘
                │
                └─ 建立 SSHClient
                        │
                        ▼
                 ConnectionStatus.connected
```

---

## 3. Shell Session 生命周期

```text
SessionManager.addSession()
        │
        ▼
ConnectionRegistry.openShell(serverId, sessionId)
        │
        ▼
ServerConnectionController.openShell()
        │
        ▼
SSHService.openShell()
        │
        ▼
SSHSession <-> Terminal
        │
        ├─ stdout/stderr -> terminal.write()
        ├─ 用户输入 -> session.write()
        └─ resize -> session.resizeTerminal()
```

说明:

- Session 列表由 `SessionManagerNotifier` 管。
- 真实 Shell runtime 由 `ServerConnectionController` 管。

---

## 4. 自动重连数据流

```text
SSH client.done / 网络中断
        │
        ▼
ServerConnectionController.onTransportLost()
        │
        ▼
状态切换为 reconnectWait
        │
        ▼
指数退避计时器
        │
        ▼
reconnect()
        │
        ├─ 重新建连
        ├─ 恢复 reopenOnReconnect 的 Shell
        └─ 恢复 autoStart 端口转发
```

网络事件来源:

```text
Connectivity.onConnectivityChanged
        │
        ▼
NetworkMonitorService
        │
        ▼
ForegroundServiceCoordinator
        │
        ├─ onNetworkLost()
        └─ onNetworkRestored()
```

## 5. AI 工具检测数据流

```text
AI Assistant / AI Chat 需要可用工具
        │
        ▼
AIToolDetectionCacheService.read(serverId)
        │
        ├─ 命中最近成功路径 -> 先验证该工具
        └─ 未命中 -> 全量检测
                │
                ▼
       OpenCodeDetector.detect()
       OpenClawDetector.detect()
                │
                ├─ which <tool>
                ├─ 检测远端服务是否已运行
                └─ 必要时自动启动
                        │
                        ▼
              ToolDetectionResult
                        │
                        ▼
       writeDetectionResults / markLastSuccessful
```

---

## 6. AI 查询数据流

```text
用户发送 prompt
        │
        ▼
AISessionNotifier.sendQuery()
        │
        ├─ 持久化 user message
        ├─ 构建执行链
        │    OpenCode: http -> pty
        │    OpenClaw: http -> execute -> pty
        └─ 逐个模式尝试
                │
                ▼
         Adapter.query()
                │
                ├─ HTTP 模式:
                │    launcher.ensureRunning()
                │    -> SshPortForwardService.ensureStarted()
                │    -> http 请求本地 loopback 端口
                │
                └─ SSH 模式:
                     client.execute() / client.shell()
                ▼
         AIResponseChunk stream
                │
                ├─ streamingContent 实时刷新
                ├─ 成功 -> 保存 assistant message
                └─ 失败 -> 自动降级到下一模式
```

---

## 7. 本地 HTTP 隧道数据流

```text
OpenCodeApiAdapter / OpenClawApiAdapter
        │
        ▼
SshPortForwardService.ensureStarted(client)
        │
        ▼
ServerSocket.bind(127.0.0.1, 0)
        │
        ▼
本地随机端口 <----> SSH forwardLocal(remoteHost, remotePort)
        │
        ▼
http.Client 只访问 localhost
```

特点:

- 应用不直接暴露远端服务到公网。
- 认证密码保存在本地安全存储，不写入 Hive。

## 8. 数据持久化流

```text
Provider / Controller
        │
        ▼
Repository
        │
        ├─ Hive
        │    ├─ servers
        │    ├─ known_hosts
        │    ├─ port_forward_profiles
        │    ├─ settings
        │    ├─ ai_tool_configs
        │    ├─ ai_conversations
        │    ├─ ai_chat_messages
        │    └─ ai_tool_detection_cache
        │
        └─ SecureStorage
             ├─ ssh_password_{serverId}
             ├─ ssh_key_profile_private_{keyId}
             ├─ opencode_server_password_{serverId}
             └─ openclaw_gateway_password_{serverId}
```
