## 2. 模块职责边界

### 2.1 仓库层

- 只负责本地持久化，不直接持有连接状态。
- 统一将 Hive 与安全存储异常映射为 `AppException`。
- `ServerRepository` 额外负责配置与凭证的一致性回滚。

### 2.2 连接编排层

- `ConnectionRegistryNotifier`
  - 管理全局“服务器连接快照 / Shell 快照 / 隧道快照”。
  - 为每个服务器懒创建 `ServerConnectionController`。
- `ServerConnectionController`
  - 单服务器连接生命周期的真实执行者。
  - 负责连接、重连、Shell 打开、终端输入输出绑定、隧道恢复。
- `SessionManagerNotifier`
  - 只管理 UI/业务上可见的 Session 列表和活跃索引。
  - 真正 Shell 的创建与关闭仍委托给连接注册表。

### 2.3 AI 编排层

- `AISessionNotifier`
  - 管理单工具对话。
  - 保存消息、选择执行模式、处理自动降级、响应中断。
- `AIToolDetectionCacheService`
  - 缓存检测结果和最近成功模式，减少重复探测。

### 2.4 基础服务层

- `SSHService`
  - 负责低层连接、认证、跳板机链路、Shell 打开和 resize。
- `SshPortForwardService`
  - 负责本地 loopback 监听和 SSH forward bridge。
- `SecureStorageService`
  - 统一管理 SSH 与 AI 运行时敏感凭证。
- `NetworkMonitorService`
  - 负责网络变化事件，不直接做重连决策。

## 3. 关键运行时流程

### 3.1 SSH 建连与指纹校验

```text
ServerRepository 读取配置和凭证
        │
        ▼
ServerConnectionController.connect()
        │
        ▼
SSHService.connect() / connectViaJumpHosts()
        │
        ├─ 查询 KnownHostRepository
        │    ├─ 已存在且匹配 -> 继续
        │    ├─ 首次连接 -> 调用 TOFU 回调，确认后落盘
        │    └─ 不匹配 -> 拒绝连接
        ▼
SSHClient 建立
        ▼
绑定 client.done 监听，进入连接生命周期管理
```

### 3.2 自动重连与恢复

```text
SSH 断开 / 网络中断
        ▼
ServerConnectionController.onTransportLost()
        ▼
进入 reconnectWait
        ▼
指数退避后 reconnect()
        ▼
连接成功
        ├─ 恢复 reopenOnReconnect 的 Shell
        └─ 恢复 autoStart 端口转发
```

### 3.3 AI 查询执行

```text
AIChatScreen / AI Assistant 选择工具
        ▼
AISessionNotifier.sendQuery()
        ▼
根据检测结果构建执行链:
  OpenCode: http -> pty
  OpenClaw: http -> execute -> pty
        ▼
创建适配器并发起查询
        ▼
流式块写入 state.streamingContent
        ▼
成功后持久化 AIChatMessage / 更新 AIConversation
        ▼
失败则自动降级到下一个模式
```

### 3.4 HTTP 模式隧道

```text
OpenCode / OpenClaw adapter
        ▼
launcher.ensureRunning()
        ▼
SshPortForwardService.ensureStarted()
        ▼
localhost:random_port -> remote 127.0.0.1:service_port
        ▼
HTTP client 访问本地端口
```

## 5. 异常处理策略

- 所有持久化异常统一上抛 `AppException`。
- 连接异常分为可恢复和不可恢复：
  - 可恢复: 触发自动重连。
  - 不可恢复: 终止当前生命周期并保留错误。
- AI 模式失败不立即报死，而是按执行链自动降级。
- 中断不是异常，属于显式状态迁移，会将已生成内容以不完整消息形式落盘。
